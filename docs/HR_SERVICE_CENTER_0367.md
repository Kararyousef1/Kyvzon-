## ★★★★ العطل الأخطر: الموظف يُصدر شهادة راتبه بنفسه

نصّ السياسة القديمة حرفياً من `pg_policy`:

```
kyvzon_letter_requests_write | polcmd = '*'  (ALL)
USING/CHECK ((tenant_id = current_user_tenant_id())
             AND (current_user_is_staff()
                  OR employee_id = auth.uid()
                  OR employee_id = current_user_employee_id()))
```

`polcmd = '*'` تعني **ALL**: SELECT و INSERT و UPDATE و DELETE في سياسةٍ
واحدة. والموظف يمرّ منها بالشرط الثالث.

**المسبار بدور `authenticated` حقيقيّ (سالم · `employee`):**

```sql
UPDATE employee_letter_requests
   SET status       = 'delivered',
       document_url = 'http://fake/شهادة-راتب-مزوّرة.pdf',
       reviewed_by  = <سالم نفسه>,
       reviewed_at  = now()
 WHERE id = '…';
```
```
RLS_4 = الموظف حدّث 1 صفّاً · الحالة=delivered
        · الملفّ=http://fake/شهادة-راتب-مزوّرة.pdf
★★★★ العطل: الموظف أصدر شهادة راتبه واعتمدها بنفسه.
```

شهادة الراتب وثيقةٌ تُقدَّم للمصارف والسفارات. والموظف **يُنشئ طلبها،
ويرفع ملفّها، ويكتب أنه هو من راجعها، ويُعلن تسليمها** — بلا مرور
الموارد البشرية إطلاقاً.

### ① `verify-attendance-vocabulary-0344.sql` — صفٌّ `resolved` بلا ملخّص

```

```
الملف كان يُدرج `('تصحيح 3/5', …, 'resolved', …)` بلا `resolution_summary`
ولا `resolved_at` — **وهو بالضبط العطل ⑫ الذي أُصلح**. القيد رفضه بحقّ.
أُكمل الصفّ.

### ② الملف نفسه — عبورٌ بين المستأجرين

```

```
كان يُدرج `(v_tb, v_e, …)` — موظف **ألف** داخل مستأجر **باء** — وهو
بالضبط ما يمنعه FK المركَّب. والعيّنة تحوي `v_eb` (موظف باء الحقيقيّ)
فأُصلح إليه: **الغرضُ محفوظٌ تماماً** (صفٌّ أجنبيٌّ يجب ألّا يظهر)
والدالة تُرشّح بـ`(employee_id, tenant_id)` معاً.

**العلاج مزدوج**:
