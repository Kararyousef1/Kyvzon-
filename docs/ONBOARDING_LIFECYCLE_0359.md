## الأعطال — كلٌّ منها مقيس قبل كتابة سطر واحد

المسبار: `tools/dev/_probe_0359.sql`

### ① ★★★ إنهاء الخدمة يفشل — ويترك سجلاً يتيماً

`handleOffboard` ينفّذ نداءين متتابعين **بلا معاملة**:

```js
1) offboardingRecordService.createRecord({...})              ← ينجح
2) employeeService.update(id, { is_active: false,
                                employment_status: 'terminated' })
```

و`employment_status` **لا وجود له** في `employees`:

```
PROBE_1: ERROR: column "employment_status" of relation
         "employees" does not exist
```

⇒ **سجلُّ إنهاء خدمة مكتوب والموظف ما زال نشطاً.** يظهر في «إنهاء
الخدمة» وفي دليل الفريق «نشط» في آنٍ واحد.

> ★ أضفتُ `out_orphan_active` و`out_still_active` **لكشف الحالات
> الشاذّة القائمة في البيانات** — لا لمنع تكرارها فقط.

### ② ★★★ بدء التعريف مرّتين يُضاعف المهام

لا قيد فرادة على `(employee_id, task_id)`.

```
PROBE_2: مهمّتان × ضغطتان ⇒ 4 صفوف
```

⇒ القائمة تعرض كل مهمة مرّتين، وإتمام إحدى النسختين يترك الأخرى
معلَّقة إلى الأبد.

### ③ ★★ `upsert()` اسمٌ كاذب

```js
async upsert(records) { for (…) await this.create(record) }
```
N نداءً شبكياً بلا معاملة — الفشل في المنتصف يترك **نصف تعريف**.

### ④–⑪ البقية

| # | العطل | المقيس |

| ④ | لا FK على `employee_id` في الجدولين | PROBE_4A/4B |

| الدالة | الغرض |

| `onboarding_start(employee)` | كل المهامّ في **معاملة واحدة** بـ`ON CONFLICT DO NOTHING` |
