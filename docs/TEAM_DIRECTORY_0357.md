## الأعطال — كلٌّ منها مقيس قبل كتابة سطر واحد

المسبار: `tools/dev/_probe_0357.sql`

### ① ★★★ `mood_score` عمود معدوم ⇒ «صحة 0%» للجميع أبداً

```js
avgWellness = empWellness.reduce((a,b) => a + (b.mood_score ?? 0), 0) / n
```

أعمدة `wellness_entries` الحقيقية عشرة، ليس فيها `mood_score`:
```
id · employee_id · date · score · mood · stress · energy · notes · created_at · tenant_id
```

**المقيس** (PROBE_2B — صفّان بدرجتَي 82 و 68):
```
المتوسّط الحقيقيّ = 75
والصفحة تجمع undefined ?? 0  ⇒  0
```

⇒ بطاقة «صحة: 0%» وشريطٌ **أحمر** لكل موظف في الشركة.

> **`?? 0` هو ما أخفى العطل.** لولا المُعامل لظهر `NaN` وانكشف فوراً.
> العطل نفسه في `WellnessService.getAverageScore:34`.

### ② ★★★ الربط بالمفتاح الخطأ ⇒ «0 مشاكل» للجميع أبداً

```js
incidentsData.filter(i => i.reported_by === profile.id)
```
و`profile.id` هنا **`employees.id`**، بينما:
```
incidents_reported_by_profiles_fkey  →  REFERENCES profiles(id)
```

**المقيس** (PROBE_3 — بلاغٌ واحد أبلغ عنه سالم):
```
match_by_employee_id = 0
match_by_profile_id  = 1
PROBE_3B: employees.id = profiles.id  ⇒  false
```

> هذا درس `0349` نفسه (الذي جعل «متوسط الصحة» صفراً لكل قسم) —
> **تكرّر في صفحة أخرى.**

### ③ ★★★ أربعة أعمدة فارغة

**المقيس** (PROBE_1B — على مستوى الجدول كلّه):
```
with_name_ar = 0 · with_email = 0 · with_phone = 0 · with_position = 0
```

والبيانات موجودة في `profiles` و`auth.users` ولا يقرؤها أحد. النتيجة:

| الحقل | ما يظهر |
|---|---|
| الاسم | «بدون اسم» |
| الحرف الأول | **U** للجميع (`full_name?.charAt(0) \|\| 'U'`) |
| البريد | فارغ — والبحث به بلا معنى |
| الهاتف | «غير محدد» |
| المسمّى | فارغ |

### ④ ★★ الدور من الجدول الخطأ

الصفحة تقرأ `emp.role` من `employees` — والعمود موجود لكنه **غير مُدار**:
المحفّز `tg_ensure_employee_row` لا يكتبه (PROBE_1: `role = employee` وهي
قيمة `DEFAULT`). الدور الحقيقيّ في `profiles.role`.

⇒ موظفٌ رُقّي إلى `manager` في إدارة المستخدمين يبقى «موظف» هنا أبداً.

### ⑤ ★★ `on_leave` لا تُنتَج أبداً

الصفحة تُعرّف ثلاث حالات وتحسب `is_active ? 'active' : 'inactive'` فقط.
PROBE_5: لا عمود `status` في `employees` أصلاً.
⇒ `statusLabels.on_leave` و`statusVariants.on_leave` **شيفرة ميتة**.

★ والمصدر الحقيقيّ موجود: `leaves` بحالة `'موافق'` ومدى يغطّي اليوم.

### ⑥ ★★ خمسة جداول كاملة إلى المتصفّح

`findAll()` بلا حدّ على: `employees` · `departments` · `incidents` ·
`wellness_entries` · `employee_certifications` — ثم **أربع حلقات `filter`
داخل حلقة `map`** ⇒ تعقيد O(n×m) في الواجهة.

### ⑦ ★ سياسة `employees` بلا تمييز دور

PROBE_7: `kyvzon_employees_select` هي `(tenant_id = current_user_tenant_id())`
وحدها. الصفحة مسجَّلة لـHR، لكن الحماية يجب أن تكون في القاعدة لا في
التوجيه — وهو ما يُثبته سكربت RLS.
