# 0352 — إدارة الدورات والشهادات (`hr/TrainingManagementPage`)

**التاريخ:** 2026-08-07 · **المرحلة 4** — بوابة الموارد البشرية صفحة صفحة
**الملف الأصلي:** `src/pages/hr/TrainingManagementPage.tsx` (623 سطراً)

> **قاعدة هذا التوثيق:** لا يُذكر هنا أي SQL لم يُنفَّذ فعلياً على Postgres
> محلي. كل رقم ناتج تشغيل، لا تقدير.

---

## الخلاصة

صفحة كاملة لإدارة الدورات… **ولا يمكن إنشاء دورة واحدة ولا تعديلها.**
كلا الزرّين يُرسل عمودين معدومين فيرفضهما Postgres. ومعها جدول شهادات
أعمدته كلها خاطئة، وحالة «معتمدة» مكتوبة يدوياً، وتاريخ انتهاء صلاحية
موجود في القاعدة ولا يُقرأ إطلاقاً.

---

## ═══ العطل ① — ★★★ إنشاء أو تعديل أيّ دورة يفشل دائماً ═══

`TrainingManagementPage.tsx:388` يبني `courseData` وفيه حقلان معدومان:

```js
active:       data.active ?? true,
rich_content: data.richContent || EMPTY_RICH_CONTENT,
```

**ناتج التشغيل:**

```
INSERT INTO courses(…,active)
  ⇒ ERROR: column "active" of relation "courses" does not exist
INSERT INTO courses(…,rich_content)
  ⇒ ERROR: column "rich_content" of relation "courses" does not exist
```

⇒ **زرّ «إضافة دورة» وزرّ «حفظ التغييرات» معطّلان تماماً.** الصفحة كلّها
إدارةُ دورات ولا تستطيع إنشاء دورة واحدة.

★ و`convertRowToCourse` يقرأ `c.active ?? true` ⇒ **كل دورة تُقرأ
«فعّالة»** مهما كانت حالتها الحقيقية — حتى المؤرشفة.
★ و`toggleActive` يكتب `active` أيضاً ⇒ التفعيل/التعطيل يفشل.

## ═══ العطل ② — أعمدة الشهادات كلها خاطئة ═══

`CertRow` يُعرّف `title` و`issuer`. والجدول المُحقَّق:

| الصفحة تقرأ | الموجود فعلاً |
|---|---|
| `title` | `certification_name` |
| `issuer` | `issued_by` |
| — | `expiry_date` (غير مقروء) |
| — | `certification_url` · `notes` (غير مقروءين) |
| `approved` · `approval_date` | **لا وجود لهما إطلاقاً** |

```
INSERT INTO employee_certifications(…,title,issuer,…)
  ⇒ ERROR: column "title" of relation … does not exist
```

⇒ عمودا «الشهادة» و«الجهة المانحة» **فارغان أبداً**.

## ═══ العطل ③ — «معتمدة» قيمة مكتوبة يدوياً ═══

```js
approved: true,                                        // :208
completed: certifications.filter((c) => c.approved)    // :478
```

ثابت `true` لكل شهادة ⇒ بطاقة «إتمام التدريب» = **100% أبداً**.
ولا عمود اعتماد في الجدول أصلاً — فالمؤشّر بلا مصدر.

## ═══ العطل ④ — ★ انتهاء الصلاحية مُهمَل تماماً ═══

`expiry_date` موجود ولا يُقرأ في أي موضع.

**مُثبَت** (شهادة انتهت قبل 30 يوماً): `شهادات منتهية الصلاحية = 1`
والصفحة تعرضها **«معتمدة»** كسائرها.

⇒ شهادة سلامة منتهية تظهر سارية. في سياق الجودة والسلامة المهنية هذا
**خطرٌ تنظيميّ** لا مجرّد عيب عرض.

## ═══ العطل ⑤ — اسم الموظف وبريده فارغان ═══

```
employees.email        = <NULL>
employees.full_name_ar = <NULL>
```

⇒ عمود الموظف يعرض حرفاً أول فارغاً واسماً فارغاً.

## ═══ العطلان ⑥ و⑦ ═══

الترتيب بـ`full_name_ar` وهو NULL للجميع · والبحث بـ`toLowerCase()`
الذي لا أثر له على العربية.
