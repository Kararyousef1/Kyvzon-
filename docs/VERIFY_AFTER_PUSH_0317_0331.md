## ثانياً: الفحص الآلي — دقيقة واحدة

### الخطوة ١

افتح **لوحة Supabase ← SQL Editor ← New query**

### الخطوة ٢

الصق محتوى هذا الملف كاملاً واضغط **Run**:

```

```

> ★★ **للقراءة فقط تماماً.** لا `INSERT` ولا `UPDATE` ولا `DELETE` ولا
> `DDL`. آمن للتشغيل في أي وقت وأي عدد من المرات.

### الخطوة ٣ — اقرأ عمود «الحالة»

النتيجة المتوقّعة **27 صفاً**:

| الحالة | العدد المتوقَّع | ماذا تعني |
|---|---|---|
| ✅ | 24 | سليم |
| ⚠️ | 3 | معلومة لا عطل (انظر أدناه) |
| ❌ | **0** | ← **إن ظهر أي ❌ توقّف ولا ترفع** |

### الثلاثة ⚠️ المتوقّعة — كلّها سليمة

| الصف | القيمة المتوقّعة | لماذا ليست عطلاً |
|---|---|---|
| `وضع الإقفال لكل الشركات` | `off` | مقصود. `0320` ركّب البوابة معطّلة، والتشغيل قرار يدوي واعٍ |
| `ملفات بلا سجلّ موظف` | `0` | مجرد عدّاد؛ يظهر ⚠️ لأنه معلومة لا حكم |
| `دوال public الكلّية` | ~832 | عدّاد مرجعي |

### ما شُغّل فعلاً للتأكد من الأداة نفسها

الأداة اختُبرت على قاعدة Postgres 17 محلية بُنيت من **260 مايجريشن من
الصفر**، ثم كُسرت خمس مرات عمداً للتأكد أنها **تكشف**:

| الكسر المُصطنَع | ما التقطته |
|---|---|
| إسقاط `tech_export_summary` | `السجلّ الموحّد والتكاملات: 9 / 10 ❌` |
| `GRANT … TO anon` | `دوال بوابة التقنية محجوبة عن anon: 2 دالة مكشوفة! ❌` |
| إسقاط حارس على `employee_loans` | `حارس تجاوز السلسلة: 3 / 4 ❌` |
| إعادة المحفّز ذي السباق الزمني | `المحفّز ذو السباق الزمني محذوف: 1 عاد! ❌` |
| `DISABLE ROW LEVEL SECURITY` | `RLS مُفعّل على الجداول الحسّاسة: 3 / 4 ❌` |

أداة فحص لا تسقط أبداً = أداة بلا قيمة. هذه تسقط.

### ★ تصحيح علني: خطأ في أول نسخة من الأداة

النسخة الأولى فحصت وجود المحفّز `trg_notify_approval_created` وأعطت
`3 / 4 ❌`. **الخطأ كان في أداتي لا في قاعدتك:** هذا المحفّز يحذفه
`0322` **عمداً** — سباق زمني موثّق (محفّز `AFTER INSERT` على جدول الطلب
يعمل **قبل** بناء الخطوات، فيُشعِر بلا معتمِد). نُقل إلى جدول الخطوات
باسم `trg_notify_approval_step`.

صُحّح الفحص، وأُضيف فحص **معاكس**: وجود `trg_notify_approval_created`
يعني عودة السباق الزمني ⇒ `❌`.

## رابعاً: قبل الرفع — رتّب ما ستدفعه

`git status` عندك يُظهر ثلاث مشكلات:

### ★ المشكلة ①: الفرع متشعّب

```
Your branch and 'origin/…' have diverged,
and have 2 and 1 different commits each, respectively.
```

لديك التزامان محليان، وعلى الخادم التزام مختلف. **لا ترفع قبل حلّ هذا**
وإلا رفضك Git أو أضعتَ عمل الخادم.

افحص أولاً ما على الخادم:

```powershell
git fetch origin
git log --oneline HEAD..origin/remediation/p0-security-and-build-health
```

- إن كان التزام الخادم شيئاً تريده ⇒ `git pull --rebase origin remediation/p0-security-and-build-health`
- إن كان قديماً لا قيمة له ⇒ أخبرني قبل أي `--force`

### ★★ المشكلة ②: ملف محذوف بلا قرار

```
deleted: docs/e-procurement/GAP_COMPLETION_ROUND2_2026-08-04.md
```

وفي نفس الوقت untracked:

```
docs/e-procurement/GAP_COMPLETION_ROUND2_2026-08-03.md
```

يبدو أنه **أُعيدت تسمية** (`08-04` ← `08-03`). تحقّق أنه مقصود قبل
تثبيت الحذف.

### المشكلة ③: `package.json` و`package-lock.json` معدّلان

راجع `git diff package.json` — إن كان تغييراً مقصوداً فلا بأس، وإن كان
أثراً جانبياً لـ`npm install` فأرجعه.
