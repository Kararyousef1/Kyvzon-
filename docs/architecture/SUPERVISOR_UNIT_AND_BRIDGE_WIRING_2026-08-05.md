## الجزء (أ): ربط الجسور — الفجوة التي أعلنتُها

في الجولة السابقة قلتُ صراحةً: «الجسور موجودة ومُختبَرة، لكن صفحات المالية والتصنيع لا تستدعيها بعد». هذا سُدَّ الآن.

### المالية

```ts
async submitEntry(entryId, reason) {
  const { data, error } = await supabase.rpc('submit_journal_entry', ...);
  if (error) throw new Error(error.message);

  const { error: bridgeError } = await supabase.rpc('create_financial_approval', {
    p_request_type: 'journal_entry', p_reference_id: entryId,
  });
  if (bridgeError) logger.warn('تعذّر إنشاء طلب موافقة للقيد — القيد قُدِّم بنجاح', ...);
  return data;
}
```

**قرار دقيق:** فشل الجسر **لا يُفشل التقديم**. القيد قُدِّم فعلاً في القاعدة، وإرجاع خطأ يوهم المستخدم بأن العملية لم تتم. نُسجّل تحذيراً — والجسر آمن للتكرار فتُصحَّح الحالة بإعادة التقديم.

اختبار العقد يتحقق من هذا صراحةً: `expect(afterBridge).not.toMatch(/throw new Error\(bridgeError/)`.

### التصنيع — مشكلة أعمق

`approve_mrp_bom_version` تنقل النسخة مباشرة إلى `effective` **بلا مرور بسلسلة موافقة**. فمكان الطلب هو **التقديم للمراجعة** لا الاعتماد.

أضفتُ `submitForApproval` التي تُنشئ الطلب وتنقل الحالة إلى `in_review`، وزراً في واجهة BOM. و`approve` القديمة **بقيت** للتوافق الخلفي.

## الجزء (ب): وحدة المشرف — الفصل التنظيمي

### المبدأ

> **المدير يعتمد · المشرف يتابع.**

هذا انعكاس للواقع لا تقييد تقني: الإذن بالخروج قرار إداري، والمشرف مسؤول عمّن هو خارج الموقع الآن ومن تأخّر.

**فلا دالة قرار في `0307` إطلاقاً.**

### حارس بنيوي — لا مجرد غياب

لم أكتفِ بعدم كتابة دالة قرار. أضفتُ حارساً يفحص **تعريف الدوال نفسها** في القاعدة:

```sql
SELECT pg_get_functiondef(p.oid) INTO v_def ...
ASSERT v_def !~* 'UPDATE\s+public\.employee_movement_permits',
  format('0307 failed: %s must not modify permits (supervisor cannot approve)', v_fn);
```

فلو أضاف أحد لاحقاً تعديلاً على التصاريح داخل دالة مشرف، **يفشل المايجريشن**.

### تفصيل: «الوردية» نافذة متحركة

`shift_code` في `custom_permissions` نصّ حر بلا أوقات محدَّدة. فالوردية هنا = آخر N ساعة (افتراضياً 12، تغطي أطول وردية معتادة) — وثّقتُ ذلك في المايجريشن بدل ادّعاء ربط بجدول ورديات غير موجود.

## اختباران أصلحتُهما

**١. إنذار كاذب:** `/decide|approve/i` طابقت كلمة داخل **التعليق** الذي يشرح المنع. أصلحتُه ليفحص الشيفرة مجرّدة من التعليقات — حجب الكلمة من التوثيق كان سيدفع لحذف شرح مفيد.

**٢. اختبار كسرتُه:** «يُخفي صفحات الوحدة غير المُسنَدة» كان يؤكد `hasPortalUnit('manager', ...)`. بعد تعميم الحارس ليدعم المشرف صار يقرأ `UNIT_PAGE_BASE_ROLE` — لأن الفحص بالمدير وحده كان **سيُخفي صفحة المشرف عن المشرف**.
