## 🔴 البُغ الحرج المكتشف والمُصلَح

### إنشاء أي طلب شراء كان يفشل

```
ERROR: column b.name does not exist
```

**السبب الجذري:** في `0198` يُبنى استعلام **ديناميكي** يحوي:

```sql
COALESCE(b.budget_name, b.name, 'Budget')
```

لكن جدول `budgets` لا يملك عمود `name` إطلاقاً — الموجود `budget_name` فقط.

**لماذا لم يُكتشف سابقاً؟** لأن الاستعلام داخل `EXECUTE`، فلا يتحقق منه Postgres عند إنشاء الدالة، بل عند **أول استدعاء فعلي**.

**سلسلة الأثر:**
```
إنشاء طلب شراء → create_purchase_requisition_full
                → check_pr_budget_extended  ← يفشل هنا
                → الطلب لا يُنشأ إطلاقاً
```

أي أن **الوحدة 01 كانت معطّلة كلياً في وقت التشغيل** رغم نجاح كل الفحوصات الثابتة.

**الإصلاح (`0257`):** اكتشاف عمود الاسم من `information_schema` بدل افتراضه — بنفس الأسلوب الذي تتبعه الدالة أصلاً مع عمود المبلغ. التوقيع ونوع الإرجاع مطابقان للأصل تماماً.

> هذا **ثالث** بُغ من نفس الفصيلة (بعد `get_ap_aging` و`spend_transactions.category_code`).
> القاعدة المستفادة: **لا يُوثق بأي SQL لم يُنفَّذ فعلياً.**
