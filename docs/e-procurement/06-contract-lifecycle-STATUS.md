## 🔴 ثغرتا حوكمة مكتشفتان

### 1) إنهاء عقد **بلا سبب**

```sql
SELECT public.terminate_contract(<id>, '');   -- كان ينجح!
```

يخالف مبدأ المنصة: كل إجراء حسّاس يتطلب سبباً نصياً يُسجَّل في التدقيق. عقد يُنهى بلا سبب = ثغرة حوكمة حقيقية.

### 2) إعادة إنهاء عقد منتهٍ — **تزوير للسجل**

عقد بحالة `terminated` كان يُنهى مجدداً، فيُستبدل **سبب الإنهاء الأصلي وتاريخه**:

```
CON-2026-86776 | terminated | "مرة ثانية"   ← ضاع السبب الأول
```

هذا أخطر من الأولى: يسمح بمحو الأثر التاريخي لقرار قانوني.

**الإصلاح (`0263`):** `CONTRACT_TERMINATION_REASON_REQUIRED` و`CONTRACT_ALREADY_TERMINATED`.
