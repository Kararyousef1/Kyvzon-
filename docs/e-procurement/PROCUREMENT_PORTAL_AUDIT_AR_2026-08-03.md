## 2) 🔴 الفجوة الأخطر: عزل التكامل

### أ) المشتريات لا تُغذّي بوابة المخزون

`0199_procurement_po_gr_completion.sql` ينشئ جدولاً **خاصاً به**:

```sql
CREATE TABLE IF NOT EXISTS public.inventory_transactions (
  item_code TEXT,  -- نص حر، لا مفتاح أجنبي
  ...
);
```

بينما بوابة المخزون الحقيقية تملك:

```
inventory_items · inventory_stock_balances · inventory_stock_movements
```

**نتيجة الفحص:** استخدام هذه الجداول الثلاثة في كل مايجريشنات المشتريات = **صفر**.

**الأثر العملي:** عند استلام بضاعة عبر المشتريات:
- ✅ يُسجَّل في `inventory_transactions` (جدول المشتريات).
- ❌ **لا** يزيد الرصيد في `inventory_stock_balances`.
- ❌ **لا** تظهر الحركة في الكارت المخزني.

أي أن أمين المستودع **لن يرى البضاعة المستلمة**. هذا كسر في أهم سلسلة تشغيلية.

كما يوجد تعليق مكشوف في `0185`:
```sql
-- INSERT INTO inventory_transactions ...
```

### ب) المشتريات لا تُغذّي المالية إطلاقاً

فحصت كل مايجريشنات المشتريات (0182–0203) بحثاً عن:
```
accounts_payable · journal_entries · chart_of_accounts · legal_entities
```

**النتيجة:** ملف واحد فقط (`0189_procurement_budget_real_link.sql`) و**لا شيء** يربط فاتورة المورد بـ AP.

**الأثر:** فاتورة تُطابَق ثلاثياً وتُعتمد في المشتريات، ثم يُعيد المحاسب إدخالها يدوياً في المالية. ازدواج عمل وخطر تضارب.

> **ملاحظة مهمة:** بنينا في المالية `0244` جدول `ap_invoice_lines` ودالة `create_ap_invoice_with_lines` — الجسر جاهز من طرف المالية، وينقص الربط من طرف المشتريات.

## 6) خطة إعادة الهيكلة المقترحة

بنفس منهجية المالية: وحدة وحدة، لا نغادر وحدة قبل اكتمالها.

```text
00  الأساس والتحكم        فئات، سياسات، قواعد الموافقة، الأدوار
01  طلبات الشراء           PR، الموافقات، فحص الميزانية، التجميع
02  الموردون والتأهيل       التسجيل، التأهيل، التقييم، الوثائق
03  التوريد الاستراتيجي     RFI/RFQ/RFP، المزادات العكسية، الترسية
04  أوامر الشراء والاستلام   PO، الإصدارات، GR، الإرجاع ← ⚠️ ربط المخزون
05  الفواتير والمطابقة      3-way، التسامح، الاستثناءات ← ⚠️ ربط المالية
06  العقود CLM             القوالب، الإصدارات، الالتزامات، التواقيع
07  تحليل الإنفاق          الإنفاق، الفئات، الأسعار، التنبؤ
08  التكاملات              المخزون، المالية، التصنيع
```

### الأولوية المقترحة

**الوحدتان 04 و05 أولاً** — لأنهما تحلّان الفجوة الأخطر (عزل التكامل)، وتُكملان السلسلة:

```
PR → PO → GR → المخزون (رصيد فعلي)
              ↓
        فاتورة → 3-way → المالية (AP)
```

ثم 00 و01 (الأساس والطلبات)، ثم البقية.
