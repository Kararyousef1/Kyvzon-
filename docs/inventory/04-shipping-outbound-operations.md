## الشحن — اللحظة الأخيرة التي تبني أو تهدم العلاقة مع العميل

<cite index="44-1">بمجرد السحب، تمر الأوامر عبر نقاط تفتيش الجودة قبل التعبئة. يزن الموظفون، يُعلّبون، ويُختمون الشحنات مع بيانات تعبئة وشركة الشحن — غالباً مُولَّدة تلقائياً من WMS. الطرود تُرتَّب يدوياً أو آلياً حسب الوجهة، ثم تُرحَّل لأرصفة التحميل. بيانات الشحن والملصقات تُولَّد بالتزامن مع أنظمة ERP أو WMS. الماسحات تتحقق من كل شحنة قبل المغادرة.</cite>

## أولاً: محطة التعبئة (Packing Station)

### ما تحتويه محطة التعبئة المثالية
```
المعدات:
  □ شاشة + كمبيوتر متصل بالنظام
  □ ماسح ضوئي للتحقق من الأصناف
  □ ميزان للوزن الفعلي
  □ طابعة ملصقات الشحن
  □ مواد التعبئة: صناديق، فقاعات، ورق، شريط لاصق
  □ أنواع مختلفة من الصناديق (أحجام متعددة)

البرنامج على الشاشة يُظهر:
  □ قائمة الأصناف المطلوبة في هذا الأمر
  □ حجم الصندوق المقترح بناءً على الأبعاد
  □ طريقة التعبئة الصحيحة (للمواد الهشة)
  □ متطلبات العميل الخاصة (إن وجدت)
  □ ملصق الشحن جاهز للطباعة
```

### خطوات التعبئة

**الخطوة 1: التحقق (Verification)**
```
قبل أي تعبئة:
  موظف التعبئة يمسح كل صنف:
    النظام يؤكد: ✅ هذا هو الصنف الصحيح للأمر
    إذا صنف خاطئ: ❌ تنبيه فوري — لا يُعبَّأ
    إذا كمية ناقصة: تنبيه + إعادة للسحب

  نتيجة التحقق النهائي:
    جميع الأصناف صحيحة والكميات مكتملة → انتقل للتعبئة
```

**الخطوة 2: اختيار التغليف الأمثل**
```
النظام يُقترح تلقائياً:
  بناءً على: أبعاد وأوزان الأصناف + متطلبات العميل + أنواع التغليف المتاحة

  مثال:
  صنف هش 30×20×10 سم + صنف صلب 15×15×15 سم
  → اقتراح: صندوق 40×30×25 سم مع فقاعات حماية للصنف الهش

  الهدف:
    □ حماية كافية
    □ أقل وزن ممكن (يُقلّل تكلفة الشحن)
    □ أقل حجم ممكن (يُقلّل رسوم الحجم)
```

**الخطوة 3: الوزن الفعلي وتحديث النظام**
```
الميزان يقيس وزن الشحنة كاملة (محتوى + تغليف):
  الوزن الفعلي: 4.82 KG
  الوزن الحجمي: (50×40×30) / 5000 = 12 KG

  الشحن يُحسب على: أعلى الاثنين = 12 KG (الحجمي)
  النظام يُحدّث الشحنة فوراً بالوزن الفعلي
```

## ثانياً: توليد وثائق الشحن

### الملصق (Shipping Label)
```
بيانات الملصق الكامل:
  □ اسم وعنوان المُرسِل (Shipper)
  □ اسم وعنوان المُستلِم (Consignee)
  □ رقم التتبع (Tracking Number) — فريد لكل طرد
  □ باركود رقم التتبع
  □ الخدمة: Express / Standard / Economy
  □ رمز الوجهة للفرز الآلي
  □ الوزن الفعلي والحجمي
  □ رقم أمر المبيعات / أمر العمل
  □ المحتوى (اختصاراً للجمارك إذا دولي)
  □ قيمة Incoterms (للشحن الدولي)
```

### قائمة التعبئة (Packing List)
```
وثيقة داخل كل طرد تحتوي:
  □ اسم العميل والعنوان
  □ رقم الأمر
  □ قائمة الأصناف بالتفصيل: رقم الصنف، الوصف، الكمية، الوحدة
  □ أرقام الدفعات (للمواد الخاضعة للتتبع)
  □ ملاحظات خاصة
```

### بوليصة الشحن (Bill of Lading — BOL)
للشحنات الكبيرة عبر ناقلات:
```
  □ بيانات الأطراف الثلاثة: المُرسِل، المُستلِم، الناقل
  □ وصف البضاعة والكمية الإجمالية
  □ شروط Incoterms
  □ الإعلان عن القيمة للتأمين
  □ تعليمات خاصة للناقل
```

## ثالثاً: التكامل مع شركات الشحن (Carrier Integration)

### معرفة الشركة الأنسب (Rate Shopping)
```
النظام يتحقق تلقائياً من أسعار عدة شركات شحن:
  للشحنة: وزن 12 KG، وجهة: جدة، خدمة: 2 يوم

  Aramex Express: 85 ريال — يصل يوم 23
  SMSA Priority:  78 ريال — يصل يوم 23
  DHL Express:   120 ريال — يصل يوم 22
  Aramex Ground:  45 ريال — يصل يوم 25

  القاعدة المُعرَّفة: "أرخص خيار يصل في الموعد المطلوب"
  → يختار SMSA Priority: 78 ريال
  → يُولّد رقم تتبع SMSA تلقائياً
```

### واجهة API مع شركات الشحن
```
ما يحدث تلقائياً بعد اختيار الشركة:
  ✅ إرسال بيانات الشحنة لـ API الشركة
  ✅ استلام رقم التتبع
  ✅ طباعة الملصق مباشرة
  ✅ إخطار العميل برقم التتبع عبر بريد/SMS
  ✅ تحديث حالة الأمر: "تم شحنه"
  ✅ تحديث المخزون: خصم الكمية المشحونة
```

## رابعاً: منطقة التجميع والمرحلة (Staging Area)

### تنظيم منطقة الشحن
```
المنطقة مُقسَّمة حسب:
  شركة الشحن: قسم Aramex، قسم SMSA، قسم DHL
  وقت التجميع: موجة 12:00، موجة 16:00
  الوجهة: رياض، جدة، دمام، دولي

كل طرد مُجمَّع في قسمه:
  ماسح RFID عند الباب يُسجَّل مرور كل طرد
  النظام يؤكد: هذا الطرد في القسم الصحيح؟
  إذا خطأ: تنبيه فوري قبل تحميله بالخطأ
```

### التحميل (Loading)
```
مسح كل طرد عند التحميل في الشاحنة:
  ✅ يتأكد أنه في الشاحنة الصحيحة
  ✅ يُسجَّل وقت التحميل
  ✅ يُحدَّث قائمة الشحنة (Manifest)
  ✅ التأكد من اكتمال جميع الطرود قبل إقفال الباب

الـ Manifest النهائي يُرسَل:
  → للسائق (قائمة بكل ما بالشاحنة)
  → لشركة الشحن (للتتبع)
  → لقسم المالية (للفوترة)
```

## خامساً: تتبع الشحنات (Shipment Tracking)

### التتبع الداخلي
```
بعد الشحن، كل أمر في النظام يُظهر:
  حالة الأمر: ✈ تم الشحن
  شركة الشحن: SMSA
  رقم التتبع: SMSA-2026-887441
  تاريخ الشحن: 21 يوليو 2026 — 14:35
  الوصول المتوقع: 23 يوليو 2026
  [رابط تتبع مباشر]
```

### إشعارات العملاء التلقائية
```
عند الشحن:
  "تم شحن طلبك رقم #ORD-8471. رقم التتبع: SMSA-887441. متوقع الوصول: 23 يوليو"

عند التسليم:
  "تم استلام طلبك بنجاح. نشكر ثقتكم."

عند التأخر (من شركة الشحن):
  "نعلمك بتأخر بسيط في شحنتك. الوصول المُعدَّل: 24 يوليو."
```

## سادساً: وثائق الشحن الدولي

للشحنات عبر الحدود:
```
وثائق إضافية إلزامية:
  □ الفاتورة التجارية (Commercial Invoice): قيمة البضاعة للجمارك
  □ قائمة التعبئة الدولية (International Packing List): مفصّلة للجمارك
  □ شهادة المنشأ (Certificate of Origin): بلد الصنع
  □ شهادات خاصة حسب نوع البضاعة:
      - مواد غذائية: شهادة صحية
      - كيماويات: MSDS (بيانات السلامة)
      - معدات: شهادة مطابقة

Incoterms الأكثر استخداماً:
  EXW: العميل يتحمل كل شيء من مستودعنا
  FOB: نتحمل حتى الميناء، ثم العميل
  CIF: نتحمل الشحن والتأمين لميناء الوصول
  DDP: نتحمل كل شيء حتى باب العميل
```
