## لماذا هذه الوحدة أولاً؟

كل تصريح خروج، وكل زيارة ميدانية، وكل مخالفة تُسجَّل لاحقاً — تعتمد على
ثلاثة أشياء تُبنى هنا: **الوجهات المنظَّمة**، و**السياسات القابلة للضبط**،
و**مسار التدقيق**.

النظام الحالي يفشل تحديداً لغياب هذه الثلاثة:

```sql
destination VARCHAR(300)   -- نص حر
```

هذا العمود وحده يجعل التحليل مستحيلاً: «مكتب المدير»، «مكتب المدير العام»،
«مكتب م. العام»، «المدير» — أربعة صفوف لوجهة واحدة. لا يمكن حساب «أكثر
الوجهات زيارة»، ولا التحقق من وصول الموظف فعلاً، ولا حساب المسافة.

**الوحدة E00 تحلّ ذلك بسجل مواقع موحَّد بإحداثيات وأسوار جغرافية.**

# الصفحة 1 — لوحة الحركة

## الغرض
شاشة يفتحها مسؤول الموارد البشرية أو مدير الأمن صباحاً ليعرف في **خمس
ثوانٍ**: كم شخصاً بالخارج الآن؟ هل أحد متأخر؟ ما الذي يحتاج تدخّلاً؟

## التخطيط

```
┌──────────────────────────────────────────────────────────────┐
│  [MovementUnitNav — بطاقات الوحدات السبع أفقياً]             │
├──────────────────────────────────────────────────────────────┤
│  🚶 بالخارج الآن   ⏰ متأخرون   📋 تصاريح اليوم   ⚠️ مخالفات │
│       12                3            28              2       │
│    من 340 موظف      🔴 تدخّل      18 معتمد        هذا الشهر  │
├───────────────────────────────┬──────────────────────────────┤
│  من بالخارج الآن (حي)         │  بانتظار موافقتك             │
│  ─────────────────────────    │  ──────────────────────      │
│  🟢 أحمد · البنك · 25 د متبقية│  سارة · مراجعة طبية · 3 س   │
│  🟡 محمد · العميل · 8 د       │  خالد · زيارة عميل · 1 س    │
│  🔴 علي · التدريب · +18 د     │  [اعتماد] [رفض] [تفاصيل]    │
│  [عرض الكل]                   │                              │
├───────────────────────────────┴──────────────────────────────┤
│  نشاط الحركة — آخر 7 أيام (رسم بياني عمودي)                  │
│  خروج ▓▓▓▓  عودة ▓▓▓▓  متأخر ▓                              │
└──────────────────────────────────────────────────────────────┘
```

## بطاقات المؤشرات — التعريف الحسابي الدقيق

| البطاقة | الحساب | التلوين |
|---|---|---|
| بالخارج الآن | `COUNT(*) WHERE status='out'` | رمادي دائماً |
| متأخرون | `status='out' AND NOW() > planned_return_at + grace` | 🔴 إن > 0 |
| تصاريح اليوم | `COUNT(*) WHERE DATE(created_at)=CURRENT_DATE` | مع تفصيل الحالات |
| مخالفات الشهر | `COUNT(*) WHERE status='open'` | 🟠 إن > 0 |

> **مهم:** «متأخر» يحتسب `overdue_grace_minutes` من السياسات (افتراضي 15
> دقيقة). لا تُعلِن التأخر لحظة انقضاء الوقت — هذا يولّد إنذارات كاذبة.

## قائمة «من بالخارج الآن»

لكل صف:
```
صورة الموظف · الاسم · القسم · الوجهة · خرج منذ · المتبقي ⏱
🟢 متبقٍ > 25% من المدة
🟡 متبقٍ ≤ 25% من المدة
🔴 تجاوز المدة + مهلة السماح
```
إجراءات سريعة: `اتصال` · `تمديد` (بسبب) · `تسجيل عودة` · `تصعيد للمدير`.

## التحديث الحي
`supabase.channel()` على `employee_movement_log` — تحديث فوري عند أي
خروج/عودة. تراجع (fallback) إلى `polling` كل 30 ثانية إن فشل الاتصال.

## الصلاحيات
| المستوى | ما يراه |
|---|---|
| `viewer` | المؤشرات + القائمة — بلا إجراءات |
| `operator` | + تسجيل العودة |
| `supervisor` | + الاعتماد والتمديد والتصعيد |
| `admin` | كل شيء |

# الصفحة 2 — المواقع والوجهات

> **أهم صفحة في الوحدة.** كل ما بعدها يعتمد عليها.

## الغرض
بناء سجل موحَّد للأماكن التي يذهب إليها الموظفون: فروع الشركة، البنوك،
الدوائر الحكومية، مواقع العملاء، المستشفيات.

## التخطيط

```
┌─────────────────────────────┬────────────────────────────────┐
│  🔍 بحث   [+ موقع جديد]     │                                │
│  ─────────────────────────  │      🗺️ الخريطة (Leaflet)      │
│  📍 المكتب الرئيسي          │                                │
│     office · بغداد          │    ● المكتب الرئيسي            │
│  📍 مصرف الرافدين — الكرادة │      ○ ← دائرة السور 150م      │
│     bank · 3.2 كم           │                                │
│  📍 مستودع أبو غريب         │    ● مصرف الرافدين             │
│     warehouse · 18 كم       │                                │
│  📍 عميل: شركة النور        │    ● مستودع أبو غريب           │
│     customer · 7 كم         │                                │
│  ─────────────────────────  │                                │
│  فلاتر: النوع · المدينة ·   │  [تكبير] [تصغير] [ملء الشاشة] │
│         الحالة              │                                │
└─────────────────────────────┴────────────────────────────────┘
```

النقر على صف يركّز الخريطة عليه. النقر على علامة يفتح تفاصيله.

## نموذج الموقع — كل حقل بالتفصيل

### القسم الأول: الهوية
| الحقل | النوع | القاعدة |
|---|---|---|
| كود الموقع | نص | **يُولَّد تلقائياً** `LOC-00001` — للقراءة فقط |
| الاسم بالعربية | نص | **إلزامي** — ≥ 3 أحرف |
| الاسم بالإنجليزية | نص | اختياري |
| النوع | قائمة | **إلزامي** — 12 قيمة (أدناه) |

**قيم النوع الاثنتا عشرة:**
```
office         مكتب الشركة
branch         فرع
warehouse      مستودع
plant          مصنع
customer       موقع عميل
supplier       موقع مورد
depot          مستودع تجميع
fuel_station   محطة وقود
service_center مركز خدمة
port           ميناء
border         منفذ حدودي
other          أخرى
```

### القسم الثاني: الموقع الجغرافي
| الحقل | النوع | القاعدة |
|---|---|---|
| خط العرض | `NUMERIC(10,7)` | **بالنقر على الخريطة — لا كتابة يدوية** |
| خط الطول | `NUMERIC(10,7)` | نفسه |
| نصف قطر السور | عدد صحيح (متر) | افتراضي 150 · **يُرسم دائرة حية** |
| العنوان | نص | اختياري |
| المدينة · المحافظة | نص | اختياري |
| الدولة | رمز | افتراضي `IQ` |

> **قاعدة UX إلزامية:** الإحداثيات تُلتقط بالنقر على الخريطة أو بالبحث عن
> عنوان (Nominatim). حقلا الأرقام للعرض فقط. سبب ذلك: خطأ رقم واحد في
> خط العرض ينقل الموقع مئات الكيلومترات، وتفشل كل عمليات التحقق من السور.

**تفاعل نصف القطر:** تغيير القيمة يعيد رسم الدائرة فوراً على الخريطة.
هكذا يرى المستخدم إن كان السور يغطي المبنى أم يمتد للشارع المجاور.

### القسم الثالث: الربط بكيانات Kyvzon
| الحقل | يربط بـ | الغرض |
|---|---|---|
| الفرع | `branches` | توحيد فروع الشركة |
| المستودع | `inventory_warehouses` | ربط بالمخزون |
| المورد | `suppliers` | ربط بالمشتريات |

اختيار عبر بحث — **لا لصق UUID** إطلاقاً.

### القسم الرابع: ساعات العمل والقيود
```
ساعات العمل — 7 صفوف (الأحد … السبت)
  اليوم | مفتوح؟ | من      | إلى
  الأحد |   ✓    | 08:00  | 16:00
  الجمعة|   ✗    |   —    |  —
```
يُخزَّن `JSONB`:
```json
{"sun":{"open":"08:00","close":"16:00"},"fri":null}
```

| الحقل | الاستخدام |
|---|---|
| عدد الأرصفة | للوجهات اللوجستية |
| يتطلب موعداً؟ | يمنع الزيارة بلا حجز |
| ملاحظات الدخول | «البوابة الشمالية · اطلب بطاقة زائر» |

> **قاعدة عمل:** إنشاء تصريح لوجهة **خارج ساعات عملها** يُظهر تحذيراً
> أصفر — لا منعاً. أحياناً تكون الزيارة مبرَّرة.

## الإجراءات

| الإجراء | الشرط |
|---|---|
| تعديل | `supervisor` فأعلى |
| **أرشفة** | سبب نصي إلزامي (≥ 10 أحرف) |
| تفعيل | من الأرشيف |
| نسخ | لإنشاء موقع مشابه |

> ⛔ **لا حذف نهائي.** الأرشفة تُخفي الموقع من الاختيار وتبقي التاريخ سليماً.
> حذف موقع مرتبط بـ 500 حركة سابقة يفسد كل التقارير.

## حالات الحافة
| الحالة | السلوك |
|---|---|
| موقع بلا إحداثيات | يُقبل، لكن بشارة ⚠️ «لا تحقق GPS» |
| موقعان بنفس الإحداثيات | تحذير عند الحفظ — لا منع |
| نصف قطر > 5 كم | تحذير «سور واسع جداً» |
| أرشفة موقع له تصاريح نشطة | **منع** + قائمة التصاريح |

## جدول السياسات المرجعي

| المفتاح | النوع | الافتراضي | الأثر عند التغيير |
|---|---|---|---|
| `max_permit_duration_minutes` | int | 240 | تصاريح جديدة فقط |
| `overdue_grace_minutes` | int | 15 | فوري على كل النشطة |
| `require_approval_above_minutes` | int | 60 | تصاريح جديدة |
| `approval_levels` | int | 2 | تصاريح جديدة |
| `auto_escalate_after_hours` | int | 4 | فوري |
| `allow_same_day_permit` | bool | true | تصاريح جديدة |
| `max_open_permits_per_employee` | int | 1 | فوري |
| `auto_expire_unused_hours` | int | 24 | فوري |
| `personal_exit_deducts_worktime` | bool | true | حسابات جديدة |
| `require_gps_on_field_visit` | bool | true | فوري |
| `block_checkin_outside_geofence` | bool | false | فوري |
| `notify_before_expiry_minutes` | int | 10 | فوري |

> **عمود «الأثر عند التغيير» ليس تفصيلاً ثانوياً.** تغيير
> `overdue_grace_minutes` من 15 إلى 5 يحوّل عشرات التصاريح النشطة إلى
> «متأخرة» فوراً. الصفحة **يجب** أن تُظهر: «سيؤثر هذا على 7 تصاريح نشطة».

## قواعد الحفظ
- كل تغيير يتطلب **سبباً نصياً** ويُسجَّل في `movement_audit_events`.
- عرض القيمة القديمة ← الجديدة قبل التأكيد.
- زر «استعادة الافتراضي» لكل مجموعة.
- الصلاحية: `admin` فقط.

## معايير القبول

```
□ إنشاء موقع بالنقر على الخريطة — بلا كتابة إحداثيات

□ viewer لا يرى أزرار الإجراءات

```
