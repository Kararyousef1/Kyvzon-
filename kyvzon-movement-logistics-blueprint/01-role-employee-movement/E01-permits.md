# الوحدة E01 — تصاريح الخروج
### الدور «أ»: حركة الموظفين

---

## المشكلة التي تحلّها

في الشركات بلا نظام تصاريح: الموظف يخبر مديره شفهياً، أو يكتب اسمه في
دفتر عند البوابة، أو يخرج ببساطة. النتائج المباشرة:

- **لا يعرف أحد** من بالخارج وقت الطوارئ أو الإخلاء.
- الحضور خاطئ — الموظف مسجَّل حاضراً وهو خارج المبنى ثلاث ساعات.
- لا مساءلة عن التأخر — لا سجل يُقارَن به.
- الورقة تُزوَّر أو تُفقد.

**التصريح الرقمي يحوّل هذا إلى: طلب موثَّق ← موافقة مسجَّلة ← QR غير قابل
للتزوير ← خروج مُوثَّق بالثانية ← عودة مُوثَّقة ← احتساب دقيق.**

---

## دورة حياة التصريح

```
   ┌─────────┐
   │ مسودة   │ draft
   └────┬────┘
        ↓ إرسال
   ┌─────────────────┐      رفض      ┌─────────┐
   │ بانتظار الموافقة├──────────────→│ مرفوض   │
   └────┬────────────┘               └─────────┘
        ↓ اعتماد
   ┌─────────┐   لم يُستخدم 24 ساعة   ┌─────────┐
   │ معتمد   ├──────────────────────→│ منتهٍ   │
   └────┬────┘                        └─────────┘
        ↓ مسح QR عند البوابة
   ┌─────────┐
   │ نشط     │ active — الموظف بالخارج
   └────┬────┘
        ↓ تسجيل العودة
   ┌─────────┐
   │ مكتمل   │ completed
   └─────────┘

   في أي مرحلة قبل «نشط»: إلغاء (بسبب نصي إلزامي) → cancelled
```

> **القاعدة الحاكمة:** التصريح «النشط» **لا يُلغى** — الموظف بالخارج فعلاً.
> يُغلق بتسجيل عودة أو يتحول إلى مخالفة `no_return`.

# الصفحة 1 — قائمة التصاريح

## التخطيط
```
┌──────────────────────────────────────────────────────────────┐
│ [الكل 128] [بانتظار 6] [معتمد 12] [نشط 3] [مكتمل 98] [ملغى 9]│
├──────────────────────────────────────────────────────────────┤
│ 🔍 بحث   [القسم ▾] [النوع ▾] [الفترة ▾]  [+ تصريح] [تصدير]  │
├──────────────────────────────────────────────────────────────┤
│ الرقم    │ الموظف │ النوع  │ الوجهة   │ الخروج │ الحالة      │
│ PRM-0042 │ أحمد   │ رسمي   │ الرافدين │ 10:00 │ 🟢 نشط 25د  │
│ PRM-0041 │ سارة   │ طبي    │ ابن سينا │ 09:30 │ ⏳ بانتظار  │
│ PRM-0040 │ علي    │ شخصي   │ —        │ 08:00 │ 🔴 متأخر 18د│
└──────────────────────────────────────────────────────────────┘
```

## الأعمدة
| العمود | ملاحظة |
|---|---|
| رقم التصريح | `PRM-2026-00042` — مُولَّد |
| الموظف | صورة + اسم + قسم |
| النوع | شارة ملوَّنة |
| الوجهة | اسم الموقع (لا UUID) |
| الخروج/العودة المخطط | تاريخ+وقت |
| المدة | محسوبة |
| الحالة | شارة + عدّاد للنشط |

## أنواع التصاريح الثمانية
| النوع | الوصف | موافقة؟ | يُخصم من الدوام؟ |
|---|---|---|---|
| `personal` | شخصي | ✅ | ✅ |
| `official` | مهمة رسمية | حسب المدة | ❌ |
| `field_visit` | زيارة ميدانية | ✅ | ❌ |
| `training` | تدريب | ✅ | ❌ |
| `medical` | مراجعة طبية | ✅ | ❌ |
| `customer_visit` | زيارة عميل | ✅ | ❌ |
| `emergency` | طارئ | لاحقة | حسب السياسة |
| `delegation` | انتداب | ✅ متعدد | ❌ |

> **الطارئ استثناء مقصود:** يُنشأ ويُنفَّذ فوراً، والموافقة **بأثر رجعي**
> خلال 24 ساعة. بدون ذلك يصبح النظام عائقاً في الحالات الحرجة. لكنه
> يُعلَّم بشارة حمراء ويظهر في تقرير امتثال منفصل.

## نطاق الرؤية
| الدور | يرى |
|---|---|
| موظف عادي | تصاريحه فقط |
| مشرف | تصاريح فريقه |
| HR / `admin` | كل التصاريح |

# الصفحة 2 — تصريح جديد

## نموذج من ثلاث خطوات

### الخطوة 1: الأساسيات
```
┌────────────────────────────────────────────┐
│  ① الأساسيات   ② التوقيت   ③ المراجعة     │
├────────────────────────────────────────────┤
│  الموظف *      [🔍 بحث…] (افتراضي: أنت)   │
│  نوع التصريح * [قائمة 8 أنواع        ▾]   │
│  الوجهة *      [🔍 بحث في المواقع    ▾]   │
│     └ ☐ وجهة غير مسجَّلة (يتطلب مبرراً)   │
│  الغرض *       [نص — 10 أحرف على الأقل]   │
│  المرفقات      [رفع]                       │
└────────────────────────────────────────────┘
```

**عند اختيار الوجهة يظهر فوراً:**
```
📍 مصرف الرافدين — الكرادة
   3.2 كم · ~12 دقيقة · مفتوح حتى 14:00
   ⚠️ يتطلب موعداً مسبقاً
```
هذه المعلومة تمنع أخطاء شائعة: طلب خروج الساعة 15:00 لمكان يغلق 14:00.

> **الوجهة غير المسجَّلة:** مسموحة لكن بمبرر نصي، وتُدرَج في تقرير
> «وجهات مقترحة للإضافة» ليراجعها المسؤول ويضيفها للسجل.

### الخطوة 2: التوقيت
```
  الخروج المخطط *   [📅 التاريخ] [🕐 الوقت]
  المدة المتوقعة *  [ 60 ] دقيقة  أو  [العودة: 11:00]
  ─────────────────────────────────────────────
  ⏱ الحد الأقصى بالسياسة: 240 دقيقة
  📊 متوسط الزيارات السابقة لهذه الوجهة: 47 دقيقة
  ─────────────────────────────────────────────
  ☐ مدفوع الأجر (يُحتسب من الدوام)
  ☐ يُخصم من رصيد الإجازات
```

**التحقق الفوري:**
| القاعدة | الرسالة |
|---|---|
| المدة > الحد | 🔴 «تتجاوز الحد المسموح (240 د)» |
| خروج في الماضي | 🔴 «لا يمكن تصريح بأثر رجعي» |
| تصريح مفتوح آخر | 🔴 «لديك تصريح نشط PRM-0040» |
| خارج ساعات الوجهة | 🟡 تحذير — لا منع |
| يوم عطلة | 🟡 تحذير |
| تجاوز الحد الشهري | 🟡 «هذا تصريحك التاسع هذا الشهر» |

> **«متوسط الزيارات السابقة» ليس زينة.** إن كان المتوسط 47 دقيقة وطلب
> الموظف 180، يرى المعتمد التباين فوراً.

### الخطوة 3: المراجعة
```
  ملخص التصريح
  ─────────────────────────────────
  أحمد الزهراني · الإنتاج
  رسمي → مصرف الرافدين (3.2 كم)
  الأحد 4 أغسطس · 10:00 ← 11:00 (60 د)
  الغرض: إيداع شيكات الموردين
  ─────────────────────────────────
  سير الموافقة:
    1️⃣ محمد (مدير مباشر)  ⏳
    2️⃣ سارة (HR)          ⏳
  ⏱ التصعيد التلقائي بعد 4 ساعات
  ─────────────────────────────────
  [حفظ كمسودة]  [إرسال للموافقة]
```

> عرض **سلسلة الموافقة قبل الإرسال** يمنع سؤال «أين طلبي؟» لاحقاً.

# الصفحة 3 — تفاصيل التصريح

## التخطيط
```
┌───────────────────────────────────────────────────────┐
│ PRM-2026-00042        [🟢 نشط]   [إلغاء] [تمديد]     │
├──────────────────────────┬────────────────────────────┤
│  المعلومات               │   رمز QR                   │
│  الموظف: أحمد            │   ┌──────────┐             │
│  النوع: رسمي             │   │ ▓▓░▓▓░▓▓ │             │
│  الوجهة: الرافدين        │   │ ░▓▓░░▓░▓ │             │
│  الغرض: إيداع شيكات      │   └──────────┘             │
│  المدة: 60 دقيقة         │   صالح حتى 11:15           │
│                          │   [طباعة] [إرسال SMS]      │
├──────────────────────────┴────────────────────────────┤
│  الخط الزمني                                          │
│  ● 09:12  أنشأ أحمد التصريح                          │
│  ● 09:20  اعتمد محمد (مدير مباشر)                    │
│  ● 09:35  اعتمدت سارة (HR)                           │
│  ● 10:02  خروج — البوابة الرئيسية (مسح QR)           │
│  ○ ——     بانتظار العودة                              │
├───────────────────────────────────────────────────────┤
│  [🗺️ الخريطة: الوجهة + السور]      [المرفقات]        │
└───────────────────────────────────────────────────────┘
```

## رمز QR — الأمان
```
عند الاعتماد:
  raw_token = 32 بايت عشوائي (hex)
  qr_token_hash = SHA-256(raw_token)   ← يُخزَّن هذا فقط
  qr_expires_at = planned_return_at + مهلة السماح

النص الخام يُعرض مرة واحدة ولا يُخزَّن إطلاقاً.
```

| الخطر | الحماية |
|---|---|
| تزوير الرمز | 32 بايت عشوائي — لا يمكن تخمينه |
| تسريب من القاعدة | الهاش فقط |
| إعادة الاستخدام | `used_at` — مسح ثانٍ يُرفض |
| بعد الانتهاء | تحقق `qr_expires_at` |
| رمز موظف آخر | يعرض صورة صاحبه للحارس |

> **نفس نمط `supplier_portal_invites` المُثبت في بوابة المورد.**

## التمديد
```
سبب التمديد *  [نص إلزامي]
مدة إضافية *   [30] دقيقة (الحد: 60)
──────────────────────────────
عدد مرات التمديد السابقة: 0
```
كل تمديد يُسجَّل في التدقيق. أكثر من تمديدين → علامة في تقرير الامتثال.

## الإلغاء
```
سبب الإلغاء * [نص إلزامي ≥ 10 أحرف]
```
> نموذج داخل الصفحة — **لا `confirm()`**.

# الصفحة 4 — صندوق الموافقات

## الغرض
مكان واحد يفتحه المدير ليعتمد كل ما ينتظره — لا بحث ولا تنقّل.

## التخطيط
```
┌─────────────────────────────────────────────────────────┐
│ [بانتظاري 6] [اعتمدتها 42] [رفضتها 3] [فوّضتها 1]      │
├─────────────────────────────────────────────────────────┤
│ ⏳ 3 ساعات                                              │
│ سارة العلي · طبي · مستشفى ابن سينا                     │
│ الأحد 10:00 ← 13:00 (180 د) · مرفق: موعد طبي           │
│ 📊 سارة: 2 تصاريح هذا الشهر · التزام 100%              │
│ [✅ اعتماد] [❌ رفض] [↗️ تفويض] [👁 تفاصيل]            │
├─────────────────────────────────────────────────────────┤
│ 🔴 5 ساعات — تصعيد خلال ساعة                            │
│ خالد · زيارة عميل · شركة النور                          │
└─────────────────────────────────────────────────────────┘
[اعتماد جماعي للمحدَّد]
```

## سياق القرار — ما يراه المعتمد
```
📊 عدد تصاريح الموظف هذا الشهر (مقابل الحد)
📊 نسبة التزامه بالعودة في الوقت
📊 متوسط مدة زياراته لهذه الوجهة
⚠️ مخالفات سابقة (إن وُجدت)
📅 هل لديه اجتماع في هذا الوقت؟
```
> **بدون هذا السياق يصبح الاعتماد ختماً آلياً بلا قيمة.**

## القواعد
- **الرفض يتطلب سبباً نصياً إلزامياً.**
- الاعتماد: سبب اختياري.
- التفويض: اختيار موظف + سبب + فترة.
- الاعتماد الجماعي: للمتشابهة فقط — مع عرض العدد والتأكيد.
- التصعيد الآلي بعد `auto_escalate_after_hours` مع إشعار الطرفين.

# الصفحة 5 — قوالب التصاريح

## الغرض
الزيارات المتكررة (إيداع بنكي أسبوعي، مراجعة دائرة حكومية شهرية) لا
ينبغي إعادة كتابتها في كل مرة.

## بنية القالب
| الحقل | مثال |
|---|---|
| اسم القالب | «إيداع بنكي أسبوعي» |
| النوع | `official` |
| الوجهة | مصرف الرافدين |
| الغرض | «إيداع شيكات الموردين» |
| المدة | 60 دقيقة |
| الموظفون المسموح لهم | أحمد · سارة |
| التكرار | كل أحد 10:00 |
| موافقة مسبقة | ✅ (يتخطى سلسلة الموافقة) |

> **«الموافقة المسبقة» ميزة قوية وخطرة معاً.** قالب معتمد سلفاً يُنشئ
> تصاريح جاهزة بلا موافقة. لذلك: `admin` فقط ينشئ قوالب، وكل تصريح مولَّد
> يُعلَّم «من قالب معتمد» في التدقيق.

## معايير القبول

```
□ تصريح بغرض < 10 أحرف → مرفوض
□ عودة قبل خروج → مرفوض
□ تصريح ثانٍ والأول مفتوح → مرفوض
□ مدة > السياسة → مرفوض برسالة تذكر الحد
□ QR يُولَّد عند آخر اعتماد فقط
□ مسح QR مرتين → PERMIT_ALREADY_USED
□ QR بعد الانتهاء → PERMIT_EXPIRED
□ رفض بلا سبب → مرفوض
□ إلغاء تصريح نشط → ممنوع
□ التصعيد يعمل بعد المدة المحددة
□ الوجهة تُختار بالبحث — لا UUID
□ لا confirm() ولا prompt()
□ الموظف يرى تصاريحه فقط
□ الطارئ يُنفَّذ فوراً ويُعلَّم للمراجعة
```
