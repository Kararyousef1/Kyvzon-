# 🚪 E02 — تنفيذ الحركة والبوابة (4 صفحات)

> اللحظة التي يتحول فيها التصريح الورقي إلى واقع مُوثَّق.
> **الجمهور: الحارس** — لا موظف مكتبي. هذا يغيّر كل قرار تصميمي.

## قيود التصميم الملزمة

| القيد | السبب |
|---|---|
| أزرار ≥ 60×60 بكسل | تُستخدم باللمس ووقوفاً |
| خط ≥ 18 نقطة | شاشة بعيدة عن العين |
| ألوان صريحة (أخضر/أصفر/أحمر) | قرار في ثانية واحدة |
| يعمل بلوحة مفاتيح فقط | ماسح الباركود = لوحة مفاتيح |
| صوت للنتيجة | الحارس ينظر للموظف لا للشاشة |
| بلا قوائم متداخلة | لا وقت للتنقل |

## E02.1 — شاشة البوابة · `/execution`

```
┌──────────────────────────────────────────────────────┐
│         🔵 امسح رمز التصريح                          │
│    ┌────────────────────────────┐                    │
│    │                            │   آخر الحركات      │
│    │      [منطقة المسح]         │   ──────────       │
│    │                            │   ✅ 10:02 أحمد ↗ │
│    └────────────────────────────┘   ⬅️ 09:48 سارة ↙ │
│    أو ابحث: [____________] 🔍       ❌ 09:31 مرفوض  │
└──────────────────────────────────────────────────────┘
```

### نتائج المسح الثلاث

**✅ صالح — أخضر + صوت قصير**
```
┌────────────────────────────────┐
│  [صورة]  أحمد الزهراني         │
│          الإنتاج — خط 2        │
│  ─────────────────────────────  │
│  الوجهة: مصرف الرافدين          │
│  العودة المتوقعة: 11:00 (60 د) │
│  ─────────────────────────────  │
│      [ ✅ تأكيد الخروج ]        │
└────────────────────────────────┘
```
> **الصورة إلزامية** — الحارس يطابق الوجه بالرمز. بدونها يمكن تمرير
> رمز شخص آخر.

**🟡 تحذير — أصفر**
```
⚠️ التصريح ينتهي خلال 10 دقائق
⚠️ الموظف لديه مخالفة تأخر سابقة
   [تأكيد رغم التحذير]  [إلغاء]
```

**🔴 مرفوض — أحمر + صوت طويل**
```
❌ رمز غير صالح
   السبب: التصريح مستخدم مسبقاً (10:02)
   [إغلاق]   [تسجيل يدوي بإذن مشرف]
```

### أسباب الرفض
| السبب | الرسالة |
|---|---|
| `PERMIT_ALREADY_USED` | مستخدم في {الوقت} |
| `PERMIT_EXPIRED` | انتهت الصلاحية |
| `PERMIT_NOT_APPROVED` | لم يُعتمد بعد |
| `PERMIT_CANCELLED` | مُلغى: {السبب} |
| `INVALID_TOKEN` | رمز غير معروف |

### تسجيل العودة
نفس الشاشة تكتشف السياق: إن كان للموظف تصريح **نشط**، فالمسح = عودة.
```
⬅️ عودة — أحمد الزهراني
   خرج: 10:02 · عاد: 10:58
   المدة: 56 دقيقة (من 60) ✅ ضمن الوقت
   [ ✅ تأكيد العودة ]
```
إن تأخر:
```
🔴 متأخر 18 دقيقة
   سبب التأخر * [نص إلزامي]
   ☐ إنشاء مخالفة تلقائياً
```

# 🗺️ E03 — الزيارات الميدانية (4 صفحات)

> الفرق عن التصريح العادي: الزيارة **مخرجات** لا مجرد غياب. تنتهي بتقرير
> ونتيجة ومتابعة.

## E03.1 — جدول الزيارات · `/field-visits`
عرض تقويم (شهري/أسبوعي/يومي) + قائمة. كل زيارة بلون حسب الحالة.

## E03.2 — تخطيط زيارة · `/field-visits/plan`

```
معلومات الزيارة
  الغرض *        [قائمة: مبيعات · دعم فني · تحصيل · تدقيق · تسليم]
  العميل/الجهة * [🔍 بحث في movement_locations أو CRM]
  التاريخ *      [📅]  من [🕐] إلى [🕐]
  المشاركون *    [متعدد: 🔍 بحث]
  وسيلة النقل    [سيارة الشركة ▾] ← يربط باللوجستيات إن اختير

الأجندة  (باني سطور — لا JSON)
  ┌────────┬──────────────────────────┬─────────┐
  │ 10:00  │ عرض المنتج الجديد        │ 30 د    │
  │ 10:30  │ مناقشة العقد             │ 45 د    │

```

> **ربط وسيلة النقل** هو نقطة التقاء الدورين: زيارة تحتاج سيارة شركة
> تُنشئ طلب مركبة في الدور «ب» — دون خلط الواجهتين.

## E03.3 — تسجيل الوصول · `/field-visits/checkins`

واجهة الهاتف:
```
📍 زيارة: شركة النور
   ┌──────────────────────┐
   │   [خريطة صغيرة]      │
   │   موقعك ● ← 45 م     │
   │   الوجهة ◎            │
   └──────────────────────┘
   ✅ أنت داخل نطاق الوجهة
   دقة GPS: ±12 م
   [ 📸 صورة (اختياري) ]
   [ ✅ تسجيل الوصول ]
```

| الحالة | السلوك |
|---|---|
| داخل السور | ✅ تسجيل عادي |
| خارج السور | ⚠️ يُقبل مع علامة «للمراجعة» + سبب |
| GPS معطَّل | ❌ منع إن `require_gps_on_field_visit` |
| دقة > 100 م | 🟡 تحذير — قد يكون داخل مبنى |

> **قرار مقصود:** لا نمنع التسجيل خارج السور افتراضياً. الإحداثيات تخطئ
> داخل المباني والأقبية. نُعلّم للمراجعة بدل تعطيل الموظف.

# 📋 E04 — المهام والانتدابات (4 صفحات)

> الانتداب = سفر متعدد الأيام. يختلف عن التصريح: بدلات · سكن · تذاكر ·
> موافقة مالية.

## الحقول الإضافية
| الحقل | ملاحظة |
|---|---|
| المدينة/الدولة | وجهة السفر |
| من ← إلى | تواريخ (لا أوقات) |
| عدد الأيام | محسوب |
| بدل يومي | مبلغ × الأيام |
| السكن | فندق · شركة · شخصي |
| النقل | طيران · سيارة شركة · بري |
| التكلفة التقديرية | **يتطلب موافقة مالية** |
| مركز التكلفة | ربط بالمالية |

## دورة الانتداب
```
مسودة → موافقة المدير → موافقة مالية → معتمد
      → جارٍ → مكتمل → تقرير + تسوية مالية
```
> **الموافقة المالية شرط.** انتداب بتكلفة تقديرية دون اعتماد مالي يخلق
> التزاماً غير مرصود.

## الصفحات
`/assignments` (قائمة) · `/assignments/new` · `/assignments/:id`
(تبويبات: التفاصيل · الموافقات · المصروفات · التقرير) ·
`/assignments/calendar` (من مسافر ومتى — يمنع تعارض الفريق).

# ⚖️ E05 — الامتثال والمخالفات (4 صفحات)

## أنواع المخالفات — تعريف الكشف الدقيق

| النوع | شرط الكشف | الخطورة |
|---|---|---|
| `late_return` | `returned_at > planned_return_at + grace` | حسب الدقائق |
| `no_return` | `status='out'` بعد نهاية الدوام | 🔴 عالية |
| `no_permit` | خروج مسجَّل بلا `permit_id` | 🔴 عالية |
| `geofence_breach` | تسجيل وصول خارج السور | 🟡 متوسطة |
| `excessive_frequency` | تجاوز الحد الشهري | 🟡 متوسطة |
| `unused_permit` | معتمد ولم يُستخدم 24 ساعة | 🟢 منخفضة |
| `manual_override_abuse` | > 3 تسجيلات يدوية شهرياً | 🟡 متوسطة |

### تدرّج خطورة التأخر
```
1–15 دقيقة    → ضمن مهلة السماح — لا مخالفة
16–30 دقيقة   → 🟢 منخفضة (تنبيه فقط)
31–60 دقيقة   → 🟡 متوسطة (إشعار المدير)
> 60 دقيقة    → 🔴 عالية (تصعيد لـ HR)
```

## دورة المخالفة
```
مفتوحة → قيد المراجعة → { مُبرَّرة | جزاء | مرفوضة }
```
| القرار | المطلوب |
|---|---|
| مُبرَّرة | سبب نصي + مرفق اختياري |
| جزاء | نوع الجزاء + سبب + إشعار الموظف |
| مرفوضة | سبب نصي (خطأ في الكشف) |

> **كل إغلاق يتطلب سبباً.** المخالفة سجل يمسّ الموظف — لا تُغلق بنقرة.

## الصفحات
- `/compliance` — لوحة: معدل الالتزام · المخالفات المفتوحة · الاتجاه ·
  الأقسام الأعلى مخالفة.
- `/compliance/violations` — القائمة والمعالجة.
- `/compliance/rules` — تفعيل/تعطيل كل نوع كشف وضبط عتباته.
- `/compliance/escalations` — ما صُعِّد ولمن ومتى.

# 📊 E06 — التحليلات والتقارير (3 صفحات)

## E06.1 — لوحة التحليلات · `/analytics`

### المؤشرات
| المؤشر | الحساب |
|---|---|
| إجمالي الحركات | عدد بالفترة |
| متوسط المدة | `AVG(actual_duration_minutes)` |
| معدل الالتزام | `عاد في الوقت / الإجمالي × 100` |
| الساعات الضائعة | `SUM` مدة الخروج الشخصي المدفوع |
| متوسط التأخر | `AVG(overdue_minutes)` للمتأخرين |
| نسبة التصاريح غير المستخدمة | معتمد ولم يُستخدم |

### الرسوم
```
📊 الحركات حسب النوع (دائري)
📈 الاتجاه الشهري (خطي)
🔥 ساعات الذروة (heatmap: يوم × ساعة)
📊 مقارنة الأقسام (أعمدة)
🏆 أكثر 10 وجهات
```

> **heatmap ساعات الذروة قيمة تشغيلية حقيقية:** إن تركّز 70% من الخروج
> بين 10:00–11:00، فالبوابة تحتاج حارساً إضافياً في تلك الساعة.

## E06.2 — أنماط الحركة · `/analytics/patterns`

تحليل سلوكي:
```
🔍 موظفون بمعدل خروج شاذ (> متوسط قسمهم + 2 انحراف معياري)
🔍 وجهات بمدة زيارة أطول من المتوقع باستمرار
🔍 أيام/ساعات ذات كثافة غير معتادة
🔍 ارتباط: هل يرتفع الخروج قبل العطل؟
```
> **صياغة محايدة إلزامية.** النظام يعرض «معدل أعلى من المتوسط» لا
> «موظف مشبوه». التفسير للإدارة لا للنظام.

## E06.3 — التقارير والتصدير · `/analytics/exports`

| التقرير | المحتوى |
|---|---|
| كشف حركة موظف | كل حركاته بفترة |
| تقرير قسم شهري | ملخص + تفصيل |
| تقرير الامتثال | المخالفات ومعالجتها |
| تقرير الساعات الضائعة | للربط بالرواتب |
| سجل التدقيق | للمدققين الخارجيين |

كلها عبر `src/utils/dataExport.ts` — BOM للعربية + حماية من حقن الصيغ.
