## L00.1 — برج المراقبة · `/app/movement/logistics/foundation`

> **الشاشة الأهم في البوابة كلها.** يفتحها مدير اللوجستيات صباحاً
> وتبقى مفتوحة طوال اليوم على شاشة جانبية.

```
┌────────────────────────────────────────────────────────────┐
│ 🚚 قيد النقل 12 │ ✅ سُلِّم 47 │ ⚠️ متأخر 3 │ 🔧 صيانة 2   │
│ ⛽ 340 لتر اليوم │ 📊 استغلال 78% │ 💰 تكلفة/كم 1,240 د.ع │
├──────────────────────────────┬─────────────────────────────┤
│  🗺️ الخريطة الحية            │  الرحلات النشطة             │
│                              │  ─────────────────────────  │
│   🟢 مركبة في الوقت          │  TRP-0142 · أحمد            │
│   🟡 تأخير بسيط              │  ▓▓▓▓▓▓░░ 3/8 توقفات        │
│   🔴 متأخر / متوقف           │  ETA 14:30 · 🟢             │
│   ⚫ خارج الاتصال             │  ─────────────────────────  │
│                              │  TRP-0143 · علي             │
│  [تجميع العلامات عند >50]    │  ▓▓▓▓▓▓▓▓ 5/6 · 🟡 +12 د   │
├──────────────────────────────┴─────────────────────────────┤
│  ⚠️ يحتاج تدخّلاً                                          │
│  🔴 TRP-0139 متوقف 45 دقيقة بلا حركة — لا رد من السائق    │
│  🔴 مركبة PLT-2214: تأمين ينتهي خلال 3 أيام               │
│  🟡 3 أوامر نقل غير مخصَّصة والموعد اليوم                  │
└────────────────────────────────────────────────────────────┘
```

### حالات المركبة على الخريطة
| اللون | المعنى | الشرط |
|---|---|---|
| 🟢 | في الوقت | ETA ≤ الموعد |
| 🟡 | تأخير بسيط | تأخر 1–30 دقيقة |
| 🔴 | متأخر / متوقف | > 30 دقيقة أو توقف > 20 دقيقة بلا سبب |
| ⚫ | خارج الاتصال | لا إشارة > 15 دقيقة |

> **⚫ «خارج الاتصال» حالة منفصلة عن «متأخر» عمداً.** انقطاع الشبكة في
> منطقة نائية ليس تأخراً. الخلط بينهما يولّد إنذارات كاذبة تُفقد الثقة
> باللوحة.

### قسم «يحتاج تدخّلاً» — منطق الترتيب
```
1. رحلات متوقفة بلا سبب (خطر)
2. وثائق تنتهي خلال 7 أيام (قانوني)
3. أوامر اليوم غير المخصَّصة (تشغيلي)
4. صيانة مستحقة متأخرة
5. سائقون اقتربوا من حد ساعات القيادة
```

### الأداء
- تحديث المواقع كل **15 ثانية** (لا realtime لكل نقطة — يخنق الاتصال).
- تجميع العلامات (clustering) عند > 50 مركبة.
- الرحلات النشطة عبر Realtime على تغيّر الحالة فقط.
- بديل رشيق عند فشل تحميل البلاطات: خلفية رمادية + قائمة إحداثيات.

## L00.2 — الشبكة والمواقع · `/foundation/network`

نفس `movement_locations` لكن بمنظور لوجستي:

| إضافة عن E00 | الغرض |
|---|---|
| عدد الأرصفة | جدولة الاستلام |
| ساعات الاستلام/التسليم | نوافذ زمنية للتخطيط |
| متوسط وقت المكوث | تقدير واقعي للتوقف |
| قيود المركبات | «شاحنات فوق 10 طن ممنوعة» |
| ارتفاع الجسر المؤدي | تفادي الاصطدام |

### عرض الشبكة
```
🗺️ خريطة بكل المواقع + خطوط الربط (lanes)
   سماكة الخط = حجم الحركة على الخط
   لون الخط = متوسط التكلفة/كم
```
> عرض «الخطوط» يكشف الأنماط: خط مستخدَم كثيراً وتكلفته مرتفعة = فرصة
> تفاوض مع ناقل.

| الحقل | القاعدة |
|---|---|

### السعة — تُستخدم في التخطيط
| الحقل | الأثر |

| الحقل | الأثر |

| مسموح بالمواد الخطرة | أنفاق ممنوعة |

## L01.3 — تفاصيل المركبة · `/fleet/:id`

ستة تبويبات:
```
نظرة عامة | المواصفات | الوثائق | الصيانة | الرحلات | التكاليف
```

**نظرة عامة:** بطاقة الحالة · آخر موقع على خريطة · العداد الحالي ·
السائق المسند · مؤشرات (استغلال · تكلفة/كم · استهلاك · تعطل).

**الوثائق:** جدول بتاريخ الانتهاء وشارة ملوَّنة:
```
🟢 > 90 يوماً   🟡 30–90   🟠 7–30   🔴 < 7 أو منتهية
```

**التكاليف:** تفصيل شهري (وقود · صيانة · تأمين · إهلاك) + تكلفة/كم +
اتجاه زمني.


الحالات الأربع: `driving` · `on_duty_not_driving` · `off_duty` · `sleeper`.

| الشرط | السلوك |
|---|---|

| راحة غير كافية | 🔴 منع بدء الوردية |

> ⚠️ **إفصاح:** هذا **ليس ELD معتمداً** من FMCSA. تسجيل يدوي/تطبيقي
> للانضباط الداخلي. لا تدّعِ الامتثال التنظيمي الأمريكي.

## L04.4 — الكفاءة وكشف الاحتيال · `/fuel/efficiency`

> **الوقود ≈ 30%+ من تكاليف الأسطول** — أعلى بند بعد الرواتب.
> كشف الاحتيال هنا عائده مباشر ومقيس.

### قواعد الكشف الست
| العلم | الشرط | الخطورة |
|---|---|---|
| 🚩 كمية > سعة الخزان | `liters > tank_capacity_l` | 🔴 |
| 🚩 تزوّدان متقاربان | فارق < 60 دقيقة | 🔴 |
| 🚩 موقع بعيد عن المسار | > 5 كم من أقرب نقطة | 🟠 |
| 🚩 عداد تراجع | `odometer < previous` | 🔴 |
| 🚩 استهلاك شاذ | > المتوسط + 30% | 🟡 |
| 🚩 خارج ساعات العمل | تزوّد ليلي بلا رحلة | 🟡 |

### المعالجة
```
كل علم → قائمة «بانتظار المراجعة»
القرار: [مبرَّر] [مخالفة] [خطأ إدخال]
  ← سبب نصي إلزامي في الحالات الثلاث
```

### تحليل الكفاءة
```
📊 لتر/100كم لكل مركبة مقابل متوسط نوعها
📈 اتجاه الاستهلاك الشهري
🏆 ترتيب السائقين بكفاءة الوقود
💡 «VH-07 يستهلك +18% عن مثيلاتها — يُنصح بفحص»
```

## معايير قبول L00–L04

```
L00
□ الخريطة تُحدَّث كل 15 ثانية
□ «خارج الاتصال» منفصل عن «متأخر»
□ تجميع العلامات عند > 50 مركبة
□ بديل رشيق بلا شبكة
□ فحوص صحة التكامل مع إعادة محاولة

L01
□ لوحة مكرَّرة → مرفوضة
□ الارتفاع والوزن محفوظان للملاحة
□ وثيقة منتهية → منع الإسناد
□ تقاعد بسبب إلزامي (لا حذف)
□ تكلفة/كم محسوبة صحيحاً

L02
□ رخصة منتهية → منع الإسناد
□ تجاوز 11 ساعة → HOS_LIMIT_EXCEEDED
□ راحة < 10 ساعات → منع الوردية
□ رابط البوابة يُعرض مرة واحدة (هاش فقط)
□ حدود HOS قابلة للضبط لكل مستأجر

L03
□ «أيها أسبق» يعمل (كم/أيام/ساعات)
□ عيب DVIR حرج → out_of_service تلقائياً
□ أمر صيانة يستبعد المركبة من الإسناد
□ القطع تُسحب من المخزون

L04
□ الأعلام الستة تعمل بالتشغيل الفعلي
□ كمية > السعة → علم فوري
□ عداد متراجع → مرفوض
□ كل قرار مراجعة بسبب نصي
```
