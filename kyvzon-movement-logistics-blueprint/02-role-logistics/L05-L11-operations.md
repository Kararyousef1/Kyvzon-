# 📦 L05 — أوامر النقل والشحنات (6 صفحات)

## المفهوم — التمييز الحاسم

```
أمر النقل (Transport Order)
   = طلب: «انقل هذا من A إلى B خلال نافذة زمنية»
   مصدره: المخزون · المشتريات · التصنيع · CRM · يدوي

الشحنة (Shipment)
   = تجميع أمر أو أكثر في وحدة نقل فعلية

الرحلة (Trip)
   = مركبة + سائق + مسار + عدة توقفات
```

**العلاقة:** عدة أوامر → شحنة واحدة → جزء من رحلة متعددة التوقفات.

> الخلط بين الثلاثة أشيع خطأ تصميمي في أنظمة النقل. الأمر **طلب**،
> والشحنة **وحدة تنفيذ**، والرحلة **موارد وزمن**.

# 📈 L11 — التكاليف والتحليلات (5 صفحات)

## L11.1 — لوحة التحليلات · `/analytics`

### المؤشرات المعيارية
| المؤشر | الحساب |
|---|---|
| التكلفة/كم | إجمالي التكاليف ÷ الكيلومترات |
| التكلفة/تسليم | إجمالي التكاليف ÷ التسليمات |
| التكلفة/طن-كم | ÷ (الوزن × المسافة) |
| **OTIF %** | سُلِّم في الوقت وكاملاً ÷ الإجمالي |
| من أول محاولة % | بلا إعادة محاولة |
| استغلال السعة % | الوزن المنقول ÷ السعة المتاحة |
| **الأميال الفارغة %** | كم بلا حمولة ÷ الإجمالي |
| متوسط المكوث | دقائق لكل توقف |
