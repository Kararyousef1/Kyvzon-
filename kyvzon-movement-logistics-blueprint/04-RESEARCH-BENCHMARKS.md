## 6) VRP — الحقيقة الهندسية

### النماذج
- **CVRP** — قيد السعة فقط.
- **VRPTW** — سعة + نوافذ زمنية + مدة خدمة. **هذا نموذجنا.**

### الأدوات المتاحة
| الأداة | اللغة | مناسبة لنا؟ |
|---|---|---|
| Google OR-Tools | C++/Python | ❌ لا تعمل في Postgres/المتصفح |
| PyVRP | Python | ❌ نفس السبب |
| OptaPlanner | Java | ❌ |
| **خوارزمية داخلية** | SQL/TS | ✅ **المختارة** |

### قرارنا
```
Nearest Neighbour (حل ابتدائي)  →  2-opt (تحسين)
```
- `PATH_CHEAPEST_ARC` في OR-Tools هو Nearest Neighbour نفسه.
- `GUIDED_LOCAL_SEARCH` أقوى من 2-opt لكنه يحتاج مكتبة.
- 2-opt يحسّن الحل الابتدائي **10–15%** عملياً.

> **إفصاح إلزامي:** حل تقريبي لا أمثل. صرّح بذلك ولا تدّعِ OR-Tools.

## 7) الخرائط — مقارنة التكلفة

| الحل | التكلفة | القيد |
|---|---|---|
| Google Maps | يتجاوز $200/شهر سريعاً | مفتاح + بطاقة |
| Mapbox | تدرّج مجاني سخي | مفتاح |
| **Leaflet + OSM** | **مجاني** | خادم عام محدود |
| MapTiler/LocationIQ | رخيص | مفتاح |

### الحزمة المختارة
```
العرض    → Leaflet + react-leaflet
البلاطات → OSM (تطوير) → self-host/تجاري (إنتاج)
الترميز  → Nominatim عبر وسيط + cache
المسارات → OSRM
```

> ⚠️ **تحذير قانوني:** خوادم OSM/Nominatim العامة **غير مسموحة تجارياً**
> ومحدودة بطلب/ثانية. الاستضافة الذاتية أو المزوّد التجاري **شرط للإنتاج**.
